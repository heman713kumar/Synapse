# App Store Optimization (ASO) — Keywords for Synapse

Play Store doesn't have a "keywords" field like the App Store, but it **heavily** indexes:
1. App name (50 char) — most important
2. Short description (80 char)
3. Long description (4000 char)
4. App category

## Recommended app name on Play Store

> **Synapse: Ideas + Collaboration**

This includes 2 high-volume search terms. Stay under 30 chars for the visible name plus optional subtitle.

## What NOT to do

- ❌ Don't keyword-stuff the description — Google will down-rank you
- ❌ Don't use competitor names ("better than LinkedIn", "Reddit clone")
- ❌ Don't promise things the app doesn't do
- ❌ Don't change the app name post-launch unless absolutely needed

## A/B testing your listing

Once approved, use Play Console **Store Listing Experiments**:
- Test 2 variants of the icon
- Test 2 short descriptions
- Test 2 feature graphics
- Test 2 screenshot orders

Run each test for at least 7 days with >5k impressions before deciding.
